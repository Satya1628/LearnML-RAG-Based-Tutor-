# LearnML — AI Data Science & Machine Learning Tutor

LearnML is a lightweight Retrieval-Augmented Generation (RAG) tutor. Ask questions about Data Science, Statistics, Machine Learning, Deep Learning and NLP, and receive structured explanations grounded in a small document library.

## What is included

- A small set of **original LearnML starter notes** so the project has useful content immediately.
- PDF, TXT and Markdown ingestion with page numbers for PDFs.
- Simple overlapping text chunking.
- Gemini embeddings (`gemini-embedding-001`) and NumPy cosine-similarity retrieval.
- Gemini-generated explanations in Beginner and Advanced modes.
- Source cards showing the retrieved document, page number (when available), URL and passage.
- Local index files, so embeddings are not regenerated whenever the app starts.

This first version is intentionally simple: it does **not** require LangChain, FAISS, Chroma, PostgreSQL, Docker or Airflow.

## Technology stack

- Python, Streamlit and NumPy
- Google Gen AI SDK (`google-genai`)
- Gemini embeddings: `gemini-embedding-001`
- Gemini generation model: `gemini-3.8-flash` by default (configurable)
- PyMuPDF for PDF extraction

## Run locally (Windows)

### 1. Extract the ZIP

Extract `LearnML_GitHub_Ready.zip`. Open PowerShell or a terminal in the extracted `LearnML` folder.

### 2. Create and activate a virtual environment (recommended)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can use Command Prompt instead:

```bat
.venv\Scripts\activate.bat
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Get a Gemini API key

Create an API key in [Google AI Studio](https://aistudio.google.com/app/apikey). Copy `.env.example` to a new file named `.env`, then replace the placeholder with your key:

```env
GEMINI_API_KEY=your_actual_key
GEMINI_MODEL=gemini-3.8-flash
GEMINI_EMBEDDING_MODEL=gemini-embedding-001
```

Keep `.env` private. It is excluded from Git by `.gitignore`. Do not paste your key into chat or commit it to GitHub.

### 5. Add learning material

The project already includes original starter notes in `knowledge_base/documents/`.

To download the openly licensed *Dive into Deep Learning* PDF from its official website, run:

```bash
python download_books.py
```

For *OpenIntro Statistics*, use the official [book page](https://www.openintro.org/book/os/). If you download its PDF, save it in `knowledge_base/documents/`. Check the licence notice for the exact file before redistributing it. More recommended books and licence notes are in [BOOKS_AND_LICENSES.md](BOOKS_AND_LICENSES.md).

Only add documents you are allowed to use. Original PDFs are excluded from Git by default to keep the repository small.

### 6. Build the search index

```bash
python build_index.py
```

This reads the files in `knowledge_base/documents/`, calls the Gemini embedding API and creates:

- `storage/chunks.json` — extracted text passages and source metadata.
- `storage/embeddings.npy` — the corresponding embedding vectors.

You can also open the app's **Knowledge Library** page and click **Build knowledge index**. Rebuild the index whenever you add, remove or change a source document.

### 7. Start LearnML

```bash
streamlit run app.py
```

Open the local URL printed in the terminal. Enter your Gemini API key in the app sidebar if it is not already available through `.env` or Streamlit secrets.

## Upload to GitHub and deploy

1. Build the index locally using the steps above.
2. Upload the extracted project files and folders to the root of your GitHub repository.
3. Include `storage/chunks.json` and `storage/embeddings.npy` generated by the index build. The ZIP only includes `storage/.gitkeep` because the index is created using your own API key.
4. Do **not** upload `.env`, API keys, `.venv/`, `__pycache__/` or the original large PDF files.
5. On Streamlit Community Cloud, create an app from your GitHub repository and set `app.py` as the entry point.
6. Add your key under the app's **Secrets** settings:

```toml
GEMINI_API_KEY = "your_actual_key"
GEMINI_MODEL = "gemini-3.8-flash"
GEMINI_EMBEDDING_MODEL = "gemini-embedding-001"
```

The deployed app reads the prebuilt index from the repository. When the document collection changes, rebuild the index locally and push the updated `storage/` files.

## Limitations

- The ZIP does not contain a prebuilt embedding index. You create it once using your own Gemini API key.
- This version uses straightforward cosine-similarity retrieval. It is a starter RAG implementation, not a benchmarked production search system.
- PDF page numbers refer to PDF page positions, which may differ from printed page numbers.
- Answer coverage depends on the documents indexed. The app should not be treated as a substitute for checking original sources.
- Gemini API quotas, available models and pricing may change. Review the [Gemini API documentation](https://ai.google.dev/gemini-api/docs) and [pricing](https://ai.google.dev/gemini-api/docs/pricing) before indexing large books.
